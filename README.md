# aleksozolins/homebrew-tap

Homebrew formulae by Aleks Ozolins.

```sh
brew install aleksozolins/tap/orgwarrior
```

- **orgwarrior**: [orgwarrior](https://github.com/aleksozolins/orgwarrior),
  a taskwarrior-style command line for Org mode's agenda, and
  [orgwarrior-web](https://github.com/aleksozolins/orgwarrior-web), its web
  page, in one formula (they share one engine). Both need a running Emacs
  daemon, Emacs 29 or later.
